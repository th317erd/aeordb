- **P2b-3 entry territory:** a KV stage currently creates or opens one `Arc<[u8]>` per bucket and publishes full cloned page vectors through `ReadSnapshot`; ordinary lookups are lock-free because every snapshot owns immutable old page bytes while writers update the file in place. Replacing that with naive positioned reads would silently destroy snapshot isolation. The bounded replacement therefore needs a shared version-aware page provider: current clean pages are coordinator-reserved LRU entries, pre-overwrite page versions remain pinned only while an older snapshot can observe them, and retention admission happens before disk overwrite. Full rebuild/expansion must quiesce or spill old generations rather than reinterpret overwritten bytes.
